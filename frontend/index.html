DBMS Mini Project Synopsis

Built Strictly to College Specifications

This system is built directly upon the approved College DBMS Mini-Project synopsis. It satisfies all core functional modules:

  • Registration & Authentication Module: Role-based access for Customers and Turf Managers with Bcrypt password security.
  • Turf Booking Module: Interactive slot selection with backend transaction isolation preventing double booking.
  • Turf Management Module: Comprehensive manager dashboard for creating, editing, and managing turf venues.
  • Booking History Module: Filterable reservation logs and payment tracking for customers.
  • Turf Usage & Records Module: Managerial analytics, utilization reports, and database examiner overview.
